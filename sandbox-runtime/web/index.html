⚠️ Your app isn’t live yet

Oyren is running, but nothing is being served at this URL. One of two things is missing:

1 · Start your app

Open the Oyren terminal and run your app (or ask the AI assistant to). It must listen on 0.0.0.0:$PORT — or any port you’ll expose below.

# add an oyren.yml (or oyren.ts) to your repo root
install: pnpm install
build: pnpm build      # optional
start: pnpm start      # must bind 0.0.0.0:$PORT
port: 3000

2 · Expose the port

If your app is already running but you still see this page, the port isn’t exposed. From the terminal, expose it — this URL then serves your app immediately:

oyren expose 3000     # writes port into oyren.yml & routes this URL → :3000

If your app needs to pick up the exposed port, restart it: re-run your command if you started it by hand, or oyren restart if you launched it with oyren start (managed).

Don’t have an oyren manifest? Ask the AI assistant to create your oyren.yml / oyren.ts.
